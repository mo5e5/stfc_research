# Security Policy

## Reporting a Vulnerability

Please report security issues **privately** via
[GitHub Security Advisories](https://github.com/mo5e5/stfc_research/security/advisories/new)
instead of opening a public issue.

This is a free community/hobby project — there is no guaranteed response time,
but reports are appreciated and reviewed as time allows.

## Supported Versions

Only the current `main` branch is maintained.
